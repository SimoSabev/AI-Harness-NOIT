## 1. Project instructions: CLAUDE.md, imports, rules, auto memory

Source: `CC/memory` [https://code.claude.com/docs/en/memory · 2026-10-22]

**Hierarchy (load order, broadest → most specific):**

| Scope | Location | Shared with |
|---|---|---|
| Managed policy | macOS `/Library/Application Support/ClaudeCode/CLAUDE.md`; Linux/WSL `/etc/claude-code/CLAUDE.md`; Windows `C:\Program Files\ClaudeCode\CLAUDE.md` | all users on machine |
| User | `~/.claude/CLAUDE.md` | only you, all projects |
| Project | `./CLAUDE.md` or `./.claude/CLAUDE.md` | team via VCS |
| Local | `./CLAUDE.local.md` (add to `.gitignore`) | only you, this project |

- "CLAUDE.md and CLAUDE.local.md files in the directory hierarchy above the working directory are loaded at launch. Files in subdirectories load on demand" — a subdirectory file loads "once Claude reads, writes, or edits another file in that subdirectory" (including `cat`/`head` via Bash).
- "All discovered files are concatenated into context rather than overriding each other", ordered filesystem root → cwd; `CLAUDE.local.md` appended after `CLAUDE.md` per directory.
- Delivery: "CLAUDE.md content is delivered as a user message after the system prompt, not as part of the system prompt itself." It is context, not enforcement: "To block an action regardless of what Claude decides, use a PreToolUse hook instead."
- Size: "target under 200 lines per CLAUDE.md file"; "Claude Code loads a CLAUDE.md file of up to 4 MiB in full and skips a larger file"; warnings at startup and in `/status` for over-length files.
- HTML comments (`<!-- -->`) are stripped before injection (except inside code blocks).
- `/init` generates CLAUDE.md; `CLAUDE_CODE_NEW_INIT=1` gives interactive multi-phase `/init`. `/init` imports `.cursor/rules/`, `.cursorrules`, `.github/copilot-instructions.md`; with NEW_INIT also `AGENTS.md`, `.devin/rules/`, `.windsurf/rules/`, `.windsurfrules`, `.clinerules`. `/import` brings other agents' config (MCP servers, commands, subagents, skills).
- `/doctor prompt-audit` audits instruction files (v2.1.283+).

**@imports:**
- Syntax `@path/to/import`; "Relative paths resolve relative to the file containing the import"; "maximum depth of four hops"; `@~/.claude/...` home paths allowed; spaces escaped with backslash; imports inside backticks/code blocks are not expanded.
- External imports (resolving outside working dir) in project files trigger a one-time approval dialog; user-scope files load imports without dialog (except Cowork).
- `--add-dir` directories do not load CLAUDE.md unless `CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1`.

**`.claude/rules/`:**
- `.claude/rules/*.md` discovered recursively; without `paths` frontmatter loaded at launch "with the same priority as `.claude/CLAUDE.md`".
- Path-scoped: YAML frontmatter `paths:` list of globs (e.g. `"src/api/**/*.ts"`, brace expansion `src/**/*.{ts,tsx}`); loads when Claude uses Read/Write/Edit (or `cat`/`head`) on a matching file. `paths` "is the only field Claude Code reads from a rule". Budget: 1,000 expanded patterns and 4 MiB per `paths` list.
- User-level rules: `~/.claude/rules/`. Symlinks supported; symlinks outside working dir are treated as external imports.
- Managed: `claudeMd` key in `managed-settings.json` injects org CLAUDE.md content; `claudeMdExcludes` (glob array, any scope, arrays merge) skips files — cannot exclude managed CLAUDE.md.

**AGENTS.md:** v2.1.277+ reads `AGENTS.md` (and `.claude/AGENTS.md`) when no `CLAUDE.md`/`.claude/CLAUDE.md`/`CLAUDE.local.md` is in cwd or above. "Project instructions" setting values: `claude-md-or-agents-md` (default), `claude-md-and-agents-md`, `claude-md`, `managed-only`; set via `pluginConfigs` → `cc-plugin-agents-md@builtin` → `{"options": {"instructionFiles": "..."}}` in user/`--settings`/managed settings only. Not read: `AGENTS.local.md`, `AGENTS.override.md`, `.agents/`.

**Auto memory:**
- On by default in local sessions. Kinds recorded in frontmatter `type`: `user`, `feedback`, `project`, `reference`.
- Location: `~/.claude/projects/<project>/memory/` with `MEMORY.md` index + topic files (`user_role.md`, `feedback_testing.md`…). `<project>` derived from git repo so worktrees share one directory. `autoMemoryDirectory` setting (absolute or `~/`) overrides.
- Loaded: "The first 200 lines of `MEMORY.md`, or the first 25KB, whichever comes first"; topic files read on demand.
- Disable: `/memory` toggle writes `autoMemoryEnabled` to `~/.claude/settings.json`; `"autoMemoryEnabled": false` in project settings; env `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`.
- Not loaded into subagents (except forks); subagent `memory: user|project|local` frontmatter gives a separate directory.
- Memory files exempt from `cleanupPeriodDays` sweep.

## 2. settings.json: scopes, permissions, sandbox, env, hooks

Sources: `CC/settings` [https://code.claude.com/docs/en/settings · 2026-10-22]; `CC/settings-reference` [https://code.claude.com/docs/en/settings-reference · 2026-10-22]; `CC/permissions` [https://code.claude.com/docs/en/permissions · 2026-10-22]; `CC/permission-modes` [https://code.claude.com/docs/en/permission-modes · 2026-10-22]; `CC/sandboxing` [https://code.claude.com/docs/en/sandboxing · 2026-10-22]; `CC/managed-settings` [https://code.claude.com/docs/en/managed-settings · 2026-10-22]; `CC/env-vars` [https://code.claude.com/docs/en/env-vars · 2026-10-22].

**Scopes / files:**
| Scope | File |
|---|---|
| User | `~/.claude/settings.json` |
| Shared project | `.claude/settings.json` (commit it) |
| Project local | `.claude/settings.local.json` (Claude Code adds `**/.claude/settings.local.json` to global git excludes when it creates it) |
| Managed | `managed-settings.json` + `managed-settings.d/*.json` (merged alphabetically) in `/Library/Application Support/ClaudeCode/` (macOS), `/etc/claude-code/` (Linux/WSL), `C:\Program Files\ClaudeCode\` (Windows); macOS plist domain `com.anthropic.claudecode`; Windows `HKLM\SOFTWARE\Policies\ClaudeCode` value `Settings` (REG_SZ JSON); server-managed settings from claude.ai admin console; HKCU registry (lowest) |

Plus `~/.claude.json` (account, MCP servers, per-project trust, global config). `CLAUDE_CONFIG_DIR` relocates the home config directory. `$schema`: `https://json.schemastore.org/claude-code-settings.json`.

**Precedence (highest first):** 1. Managed settings; 2. `--settings <file-or-json>` (command line, one session, ≤2 MiB file); 3. `.claude/settings.local.json`; 4. `.claude/settings.json`; 5. `~/.claude/settings.json`. "Lists merge instead of overriding" (e.g. `permissions.allow`), exceptions: `fallbackModel`, `modelPicker`, `availableModels`, `modelSettings`. Managed exceptions where a stricter lower value wins: `disableClaudeAiConnectors`, `enableArtifact:false`, `isolatePeerMachines`, `permissions.blockReadsOutsideWorkingDirectories`, `autoMode.classifyAllShell`, `remoteControlAtStartup:false`, `crossSessionInbound`, `useAutoModeDuringPlan:false`, `syncClaudeAiSkills:false`, `syncClaudeAiPlugins:false`, `maxEffortLevel` (lower cap). Settings files are hot-reloaded (`ConfigChange` hook fires); `model`, `effortLevel`, `requiredMinimumVersion` read at start only.
- `permissions.defaultMode` values `auto` and `bypassPermissions` "don't take effect from project or local settings" (v2.1.257+).
- Project `permissions.allow`, `additionalDirectories`, `extraKnownMarketplaces`, and most `env` values apply only after workspace trust; `deny`/`ask` apply immediately.
- Managed-only keys: `allowManagedPermissionRulesOnly`, `allowManagedHooksOnly`, `allowManagedMcpServersOnly`, `strictKnownMarketplaces`, `managedMcpServers`, `deniedModels`, `allowedProviders`, `claudeMd`, `modelPricing`, `requiredMinimumVersion`, `sandbox.network.allowManagedDomainsOnly`, `managedSourcesBehavior` ("first-wins" default or `"merge"`).

**Permission rules (`permissions.allow` / `permissions.ask` / `permissions.deny`):**
- Syntax `Tool` or `Tool(specifier)`. Evaluation: deny → ask → allow; "If a tool is denied at any level, no other level can allow it"; a managed deny can't be overridden by `--allowedTools`.
- Bash: `Bash(npm run *)` (space before `*` matters: `Bash(ls *)` ≠ `Bash(ls*)`), `:*` suffix equivalent. Compound separators `&&`, `||`, `;`, `|`, `|&`, `&`, newline: "A rule must match each subcommand independently". Stripped wrappers: `timeout`, `time`, `nice`, `nohup`, `stdbuf`, `command`, `builtin`, `noglob`, bare `xargs`. Deny rules match "as written" only: `Bash(curl *)` doesn't stop `/usr/bin/curl` or `sh -c 'curl …'` — "isn't a security boundary around the program".
- Parameter rules (deny/ask only): `Tool(param:value)`, e.g. `Agent(model:opus)`, `Agent(isolation:worktree)`, `Bash(run_in_background:true)`, `Bash(dangerouslyDisableSandbox:true)`; primary content fields (`command`, `file_path`, `url`…) not matchable.
- Read/Edit: gitignore-style; anchors `//path` (absolute), `~/path`, `/path` (relative to settings source), `path`/`./path` (cwd). `Edit(path)` governs Write/NotebookEdit too; `Read` deny also blocks Edit/Write on that path; applies to recognized Bash file commands (`cat`, `head`, `tail`, `sed`, `tee`) and redirections but not to arbitrary subprocesses → use sandbox for OS-level enforcement. `.claudeignore` has no effect. Negation `!` carve-outs supported.
- WebFetch: `WebFetch(domain:example.com)`, `WebFetch(domain:*.example.com)`, `WebFetch(domain:*)` (also feeds sandbox allowlist); bare `WebFetch` deny removes tool.
- MCP: `mcp__<server>__*`, `mcp__<server>__<tool>`, `mcp__<server>`; plugin servers `mcp__plugin_<plugin>_<server>__<tool>`; allow-globs only after literal `mcp__<server>__`; deny-glob `mcp__*`/`*` removes tools from context. Settings files skip `mcp__` rules with parentheses (use `--disallowedTools`).
- Agent: `Agent(Explore)`, `Agent(Plan)`, `Agent(my-agent)`, `Agent(fork)`. `Cd(...)` rules gate `/cd`. `Skill(name)` / `Skill(name *)`.
- `permissions.additionalDirectories`; `permissions.blockReadsOutsideWorkingDirectories` (v2.1.257+); `permissions.disableBypassPermissionsMode: "disable"`; `permissions.disableAutoMode: "disable"` (also top-level `disableAutoMode`).
- "Yes, and don't ask again" saves allow rules to `.claude/settings.local.json` at the repo root (worktrees use main checkout's root); up to 5 rules per compound command.

**Permission modes** (`--permission-mode`, `permissions.defaultMode`, Shift+Tab):
| Mode | What runs without prompt |
|---|---|
| `default` (Manual; alias `manual` v2.1.200+) | reads only, plus built-in read-only commands (`ls`, `cat`, `git status`…) |
| `acceptEdits` | file edits + `mkdir`, `touch`, `rm`, `rmdir`, `mv`, `cp`, `sed` within working dirs |
| `plan` | reads; classifier-approved commands when auto mode available (`useAutoModeDuringPlan`) |
| `auto` | everything, with a background classifier reviewing shell/network actions |
| `dontAsk` | denies anything that would prompt; allow-listed tools run |
| `bypassPermissions` | everything except "actions no mode auto-approves" |
- Built-in default: `auto` in terminal/VS Code from v2.1.283 (v2.1.228 on macOS/Linux/WSL, v2.1.233 Windows for the auto default); `claude -p` and Agent SDK start in `default`; "On v2.1.302 and later, calls needing approval are denied unless an allow rule, hook, or `canUseTool` callback approves them."
- Auto mode classifier: default model Claude Sonnet 5 (Sonnet 4.6 when session on 4.6); override `CLAUDE_CODE_AUTO_MODE_MODEL` (v2.1.302+); `CLAUDE_CODE_AUTO_MODE_SERVER=0` forces client-side classification. Broad allow rules dropped on entry (`Bash(*)`, `Bash(python*)`, `Agent`, `Monitor`); 3 consecutive or 20 total blocks pause auto mode; blocked by default e.g. `curl | bash`, force push, `git reset --hard`, `terraform destroy`, launching agents with `--dangerously-skip-permissions`. Requires Opus 4.6+/Sonnet 4.6+/Haiku 5.5/Fable on Anthropic API (Sonnet 5+/Opus 4.7+ on Bedrock/Agent Platform/Foundry). Available on all plans; Team/Enterprise admins can disable. Docs warn auto mode "does not guarantee safety". `autoMode.environment`, `autoMode.allow`, `autoMode.classifyAllShell`; `claude auto-mode defaults|config|reset`.
- `bypassPermissions`: `--dangerously-skip-permissions` ≡ `--permission-mode bypassPermissions`; `--allow-dangerously-skip-permissions` adds it to the Shift+Tab cycle; refused as root/sudo on Linux/macOS; refused under `--restricted` (v2.1.248+); first interactive use writes `skipDangerousModePermissionPrompt: true`; deny rules and ask rules still apply; "Only use this mode in isolated environments like containers or VMs".
- "Actions no mode auto-approves": explicit ask rules; connector tools set to `ask`; `AskUserQuestion` and MCP tools marked `requiresUserInteraction`; recognized `rm`/`rmdir` critical-path removals; cross-session messaging safeguards; reads outside working dirs under `blockReadsOutsideWorkingDirectories`.
- Protected paths (writes never auto-approved except bypass): `.git`, `.config/git`, `.vscode`, `.idea`, `.husky`, `.cargo`, `.devcontainer`, `.yarn`, `.mvn`, `.claude`, `--plugin-dir` dirs; files `.gitconfig`, `.gitmodules`, shell rc files, `.npmrc`, `.yarnrc`, `.pre-commit-config.yaml`, `lefthook.yml`, `.mcp.json`, `.claude.json`, etc.
- `--restricted` (v2.1.248+): removes command-running tools and WebFetch unless named in `--tools`, confines file tools to working dirs, loads only managed settings + `--settings`, refuses bypass.

**Sandbox (built-in sandboxed Bash tool):**
- Off by default; enable via `/sandbox` or `"sandbox": {"enabled": true}`. Built on open-source `@anthropic-ai/sandbox-runtime` (github.com/anthropics/sandbox-runtime).
- OS: "The sandbox runs on macOS, Linux, and WSL2. On native Windows, Claude Code runs commands unsandboxed." macOS = Seatbelt; Linux/WSL2 = bubblewrap (+ `socat`, optional seccomp).
- Scope: "The sandbox covers shell commands only. Claude's file tools, MCP servers, and hooks run outside it" (also Monitor/PowerShell commands and child processes are inside).
- Filesystem: default writes = working dir + per-user `$TMPDIR` + `--add-dir`/`additionalDirectories`; default reads = "Most of the machine, including credential files such as `~/.ssh` and `~/.aws/credentials`". Keys: `sandbox.filesystem.allowWrite`, `denyWrite`, `denyRead`, `allowRead`, `filesystem.disabled`, `allowManagedReadPathsOnly`; sandbox paths are plain (`~/.kube`, `/tmp/build`), unlike permission rules. Protected paths inside writable dirs: `.claude` settings/skills/agents/commands/hooks, `.mcp.json`, shell rc files, `.git/hooks`, `.git/config`, `~/.claude`, `~/.claude.json`, `.credentials.json`.
- Network: "No direct route out. Connections go through a proxy on your machine that checks each host against your allowed domains, which start empty." Linux: separate network namespace; macOS: Seatbelt blocks all but proxy. Proxy via `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY`; tools ignoring proxy vars (plain `ssh`, DB drivers), UDP/QUIC/ICMP cannot connect. Keys: `sandbox.network.allowedDomains`, `deniedDomains`, `strictAllowlist` (v2.1.219+, user/managed/--settings only), `allowManagedDomainsOnly` (managed), `allowUnixSockets`, `allowLocalBinding`, `httpProxyPort`, `tlsTerminate` (experimental), `allowAppleEvents`, `allowNestedUserNamespaces`. `WebFetch(domain:...)` allow rules merge into the allowlist. Unapproved host: prompt in Manual/acceptEdits/plan, refused in auto (unless per-command host list approved by classifier, v2.1.271+) and dontAsk, allowed in bypass.
- Modes: `sandbox.autoAllowBashIfSandboxed` (default `true`) = auto-allow sandboxed commands without prompts (deny rules, content-scoped ask rules, critical-path `rm` still apply); `allowUnsandboxedCommands: false` = strict mode (model's `dangerouslyDisableSandbox` retry ignored); `sandbox.failIfUnavailable` (CLI default: runs unsandboxed if sandbox can't start; set `true` to exit); `sandbox.excludedCommands` (e.g. `"docker compose *"`); `enableWeakerNestedSandbox` for unprivileged Docker ("considerably weakens security"); `ignoreViolations`. Setting strict mode in managed/`--settings` makes sandbox "admin-required" (repo settings can't loosen).
- Credentials: `sandbox.credentials` masking (`mask` entries need `tlsTerminate`), `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB`.
- Limitations (official): proxy "does not terminate or inspect TLS", domain fronting possible; "Allowing broad domains such as `github.com` can create paths for data exfiltration"; Unix socket (`/var/run/docker.sock`) grants host access; "Effective sandboxing requires both filesystem and network isolation."
- Permission interaction: with sandbox on and `autoAllowBashIfSandboxed`, a bare `Bash` ask rule is skipped for sandboxed commands; plan mode skips the substitution.

**`env` block:** any scope; "A value in a settings file `env` block replaces the inherited shell value"; cannot unset (use `""`); OTel exporter variables ignored from project/local; project `env` applies after trust; `CLAUDE_CONFIG_DIR` not settable from project/local.

**`hooks` key:** see §3 (same shape in settings files, plugins `hooks/hooks.json`, skill/agent frontmatter). `disableAllHooks` (any scope), `allowManagedHooksOnly` (managed), `allowedHttpHookUrls`, `httpHookAllowedEnvVars`.

**Other notable keys (settings-reference index):** `model`, `availableModels`, `deniedModels`, `availableModelsMatch:"exact"`, `enforceAvailableModels`, `fallbackModel` (array, capped at 3), `effortLevel`, `maxEffortLevel`, `modelSettings`, `apiKeyHelper`, `forceLoginMethod` (`claudeai`|`console`|`gateway`), `forceLoginOrgUUID`, `forceLoginGatewayUrl`, `allowedProviders` (v2.1.285+, e.g. `["anthropic","bedrock","customEndpoint"]`), `enabledPlugins`, `extraKnownMarketplaces`, `strictKnownMarketplaces`, `blockedMarketplaces`, `strictPluginOnlyCustomization`, `enabledMcpjsonServers`, `disabledMcpjsonServers`, `enableAllProjectMcpServers`, `allowedMcpServers`, `deniedMcpServers`, `managedMcpServers`, `allowAllClaudeAiMcps`, `disableClaudeAiConnectors`, `cleanupPeriodDays` (default 30), `attribution` (replaces `includeCoAuthoredBy`), `includeGitInstructions`, `statusLine`, `outputStyle`, `skillOverrides`, `disableSkillShellExecution`, `disableBundledSkills`, `teammateMode`, `worktree.baseRef|location|sparsePaths|bgIsolation`, `promptCacheTtl`/`subagentPromptCacheTtl` (`5m`|`1h`), `autoCompactWindow`, `modelPricing`, `requiredMinimumVersion`/`requiredMaximumVersion`, `processWrapper`, `skipWebFetchPreflight`, `agent`, `autoContinueAtUsageLimit`, `feedbackSurveyRate`.

**Key env vars** (`CC/env-vars`): `ANTHROPIC_API_KEY` (X-Api-Key), `ANTHROPIC_AUTH_TOKEN` (Bearer), `ANTHROPIC_BASE_URL`, `ANTHROPIC_MODEL`, `ANTHROPIC_DEFAULT_MODEL` (v2.1.236+), `ANTHROPIC_DEFAULT_OPUS_MODEL`/`_SONNET_`/`_HAIKU_`/`_FABLE_`, `ANTHROPIC_SMALL_FAST_MODEL` (deprecated), `CLAUDE_CODE_OAUTH_TOKEN`, `CLAUDE_CONFIG_DIR`, `CLAUDE_CODE_USE_BEDROCK|VERTEX|FOUNDRY`, `CLAUDE_CODE_MAX_OUTPUT_TOKENS` (unknown-model default 32000, cap 128000), `MAX_THINKING_TOKENS` (0 disables on fixed-budget models; cannot disable on Opus 5.5/Sonnet 5.5/Haiku 5.5/Fable), `CLAUDE_CODE_DISABLE_THINKING`, `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE`, `CLAUDE_CODE_AUTO_COMPACT_WINDOW` (100000–1000000), `CLAUDE_CODE_MAX_RETRIES` (10), `API_TIMEOUT_MS` (600000), `BASH_DEFAULT_TIMEOUT_MS` (120000), `BASH_MAX_TIMEOUT_MS` (600000), `BASH_MAX_OUTPUT_LENGTH` (30000, max 150000), `MCP_TIMEOUT` (30000 startup), `MCP_TOOL_TIMEOUT`, `CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT` (300000 net / 1800000 stdio), `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS` (120000), `MAX_MCP_OUTPUT_TOKENS` (25000), `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` (presence-based; disables auto-update, telemetry, error reporting, /feedback, feature flags), `DISABLE_TELEMETRY`, `DISABLE_ERROR_REPORTING`, `DISABLE_AUTOUPDATER`, `DISABLE_FEEDBACK_COMMAND`, `CLAUDE_CODE_ENABLE_TELEMETRY`, `CLAUDE_CODE_DISABLE_AUTO_MEMORY`, `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION` (200), `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS` (20), `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` (3), `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS`, `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS`, `CLAUDE_CODE_SIMPLE` (bare mode), `CLAUDE_CODE_SUBAGENT_MODEL`, `CLAUDE_CODE_SKIP_PROMPT_HISTORY`, `CLAUDE_CODE_PROMPT_CACHE_TTL`, `ENABLE_PROMPT_CACHING_1H`, `ENABLE_TOOL_SEARCH`, `CLAUDE_CODE_EFFORT_LEVEL`, `CLAUDE_CODE_DISABLE_1M_CONTEXT`, `CLAUDE_CODE_STOP_HOOK_BLOCK_CAP`, `CLAUDE_CODE_SESSIONEND_HOOKS_TIMEOUT_MS`, `CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS`, `CLAUDE_CODE_REMOTE` (`"true"` in cloud).

## 3. Hooks

Sources: `CC/hooks` [https://code.claude.com/docs/en/hooks · 2026-10-22] (reference, ~273k chars, read in 3 parts); `CC/agent-sdk/hooks` [https://code.claude.com/docs/en/agent-sdk/hooks · 2026-10-22].

**Events (complete list from the reference):** `SessionStart` (matchers `startup`, `resume`, `clear`, `compact`, `fork`), `Setup` (`init`/`maintenance`; only with `--init-only`, `--init`, `--maintenance`), `UserPromptSubmit`, `UserPromptExpansion`, `PreToolUse`, `PermissionRequest`, `PermissionDenied` (auto mode denials), `PostToolUse`, `PostToolUseFailure`, `PostToolBatch`, `SubagentStart`, `SubagentStop`, `TaskCreated`, `TaskCompleted`, `Stop`, `StopFailure`, `TeammateIdle`, `PreCompact` (`manual`/`auto`), `PostCompact`, `PreModelSwitch`, `PostModelSwitch`, `Elicitation`, `ElicitationResult`, `ConfigChange`, `InstructionsLoaded`, `CwdChanged`, `FileChanged`, `DirectoryAdded`, `WorktreeCreate`, `WorktreeRemove`, `MessageDisplay`, `Notification` (matchers `permission_prompt`, `idle_prompt`, `auth_success`, `elicitation_*`, `agent_needs_input`, `agent_completed`, `quota_auto_resume_*`, `plugin_notification`), `SessionEnd` (reasons `clear`, `resume`, `logout`, `prompt_input_exit`, `other`).

**Config structure** (settings.json / plugin `hooks/hooks.json` / skill & subagent frontmatter): `{"hooks": {"<Event>": [{"matcher": "Bash", "hooks": [{"type": "command", "command": "...", "args": [], "timeout": 30, "if": "Bash(rm *)", "async": false, "asyncRewake": false, "once": false, "statusMessage": "...", "shell": "bash|powershell", "onFailure": "block"}]}]}}`.
- Matchers: `"*"`/`""`/omitted = all; plain names or `"Edit|Write"` = exact list; other chars = unanchored JS regex (`"^Notebook"`, `"mcp__memory__.*"`). Tool events match tool name; others match their own field (`source`, `trigger`, `notification_type`, `agent_type`, `error`, `command_name`).
- Handler types: `command` (stdin JSON), `http` (POST JSON, same output schema; `allowedHttpHookUrls`), `mcp_tool`, `prompt` (single LLM call returning `{ok, reason, impossible}`; `model`, `continueOnBlock`), `agent` (experimental; subagent with Read/Grep/Glob, up to 50 turns). `SessionStart`/`Setup` support only `command` and `mcp_tool`.
- Timeouts: 600 s default for command/http/mcp_tool; 30 s for prompt and for `UserPromptSubmit`/`PreModelSwitch`/`PostModelSwitch`; 60 s agent; 10 s `MessageDisplay`; `SessionEnd` budget 1.5 s (`CLAUDE_CODE_SESSIONEND_HOOKS_TIMEOUT_MS`). "Exit 1 and timeouts do not block by default" → set `onFailure: "block"` (v2.1.295+) for fail-closed policy hooks.
- `if` field uses permission-rule syntax; "best-effort, so use the permission system for hard enforcement".
- Exec form (`args`) vs shell form; `${CLAUDE_PROJECT_DIR}` must be quoted in shell form.

**Input JSON (stdin):** common `session_id`, `transcript_path`, `cwd`, `hook_event_name`, `permission_mode` (`default|plan|acceptEdits|auto|dontAsk|bypassPermissions`), `prompt_id`, `scratchpad_dir`, `effort`, `agent_id`/`agent_type` (inside subagents). Tool events add `tool_name`, `tool_input`, `tool_use_id`, `mcp_server {name, source}`. PostToolUse adds `tool_response`, `duration_ms`. Stop adds `stop_hook_active`, `last_assistant_message`, `background_tasks`, `session_crons`. SubagentStop adds `agent_transcript_path`. PreCompact: `trigger`, `custom_instructions`; PostCompact: `compact_summary`. UserPromptSubmit: `prompt`. PermissionRequest: `permission_suggestions` (no `tool_use_id`). StopFailure: `error` (`rate_limit`, `overloaded`, `authentication_failed`, `oauth_org_not_allowed`, `account_on_hold`, `billing_error`, `invalid_request`, `model_not_found`, `server_error`, `max_output_tokens`, `cloud_credential_error`, `unknown`). InstructionsLoaded: `file_path`, `memory_type`, `load_reason`.

**Exit codes:** `0` = success, stdout parsed as JSON if a single object (plain text added to context for `SessionStart`/`UserPromptSubmit`); `2` = "Blocking error. On events that can block, the action stops. Stderr is the reason fed back to Claude. Exit 2 blocks even if the JSON on stdout says `allow`"; other = non-blocking error, action proceeds, user sees notice.

**JSON output:** universal `continue` (false halts Claude), `stopReason`, `suppressOutput` (no effect), `systemMessage`, `terminalSequence`; top-level `decision: "block"` + `reason` (UserPromptSubmit, PostToolUse, Stop, SubagentStop, ConfigChange, PreCompact…); `hookSpecificOutput` with `hookEventName` and:
- PreToolUse: `permissionDecision` (`allow`|`deny`|`ask`|`defer` — `defer` needs `-p`), `permissionDecisionReason`, `updatedInput` (replaces entire input), `additionalContext`. Precedence across hooks: `deny` > `defer` > `ask` > `allow`. Hook `allow` does not bypass deny/ask rules; exit 2 blocks before rules even when an allow rule matches. In plan mode hook `allow` doesn't approve non-read-only calls.
- PermissionRequest: `decision: {behavior: "allow"|"deny", updatedInput, updatedPermissions, message, interrupt}`.
- PostToolUse: `additionalContext`, `updatedToolOutput` (must match tool schema), `updatedMCPToolOutput`, `classifierContext` (v2.1.236+).
- PermissionDenied: `retry: true`. SessionStart: `additionalContext`, `sessionTitle`, `initialUserMessage` (`-p`), `watchPaths`, `reloadSkills`. UserPromptSubmit: `additionalContext`, `suppressOriginalPrompt`.
- Stop/SubagentStop: `decision: "block"` + `reason` keeps Claude working ("After 8 consecutive continuations, Claude Code overrides the next block"; `CLAUDE_CODE_STOP_HOOK_BLOCK_CAP`); `/goal` is a built-in Stop-hook shortcut.
- Strings capped at 10,000 chars; `additionalContext` is wrapped in a system reminder ("Write it as factual statements, not imperative commands").
- `CLAUDE_ENV_FILE`: SessionStart/Setup/CwdChanged/FileChanged hooks append `export` lines to it to set session env.
- Env for hooks: `CLAUDE_PROJECT_DIR` (fixed at session root, does not follow worktrees), `CLAUDE_PLUGIN_ROOT`, `CLAUDE_PLUGIN_DATA`, `CLAUDE_CODE_REMOTE`, `CLAUDE_EFFORT`, `CLAUDE_CODE_BRIDGE_SESSION_ID`; `OTEL_*` stripped.

**Security:** "Command hooks execute shell commands with your full user permissions"; interactive sessions hold back hooks until workspace trust; "`-p` or SDK session: Claude Code never shows the dialog and treats the folder as trusted, so hooks committed in a repository's `.claude/settings.json` run in a folder you've never trusted" → mitigate with `--bare`, `--setting-sources user`, or `--settings '{"disableAllHooks": true}'`.

**SDK hooks:** `options.hooks = {PreToolUse: [{matcher: "Write|Edit", hooks: [cb], timeout}]}`; callback `(input, toolUseID, {signal}) => Promise<HookJSONOutput>`; return `{}` to allow; async side-effect mode `{async: true, asyncTimeout}`. Python `HookMatcher(matcher=, hooks=[], timeout=)`; Python lacks `SessionStart`/`SessionEnd` callback hooks (shell hooks via `setting_sources` only). Multiple hooks run in parallel; most restrictive wins.
