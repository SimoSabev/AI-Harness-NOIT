## Какво е направено (D-292)
- `pnpm local`: билд → Postgres 17.6 в Docker (127.0.0.1:54329, volume; shim + миграции, без Supabase CLI) → демо хранилище →
  един акаунт `ti@mandat.local` с нова парола при всяко пускане → образите (при липса) → `next start` + worker.
- UI на Tailwind v4: вход, „Задачи“ (Чака теб / В работа / Готово), „Нова задача“, карта на задачата (статус и причина на
  обикновен език, ход в 3 стъпки, проверките с човешки имена, оцветен diff, решение, дневник). Махнати: Дъска, Харнес, Канали,
  push контролите, превключвателят на темата.
- Нова задача от UI: агенти Claude Code и Codex (нужен ключ) + три демо агента без ключ (честна поправка, трие тест,
  прескача тест). Живо обновяване на 3 s, докато има активна задача.
