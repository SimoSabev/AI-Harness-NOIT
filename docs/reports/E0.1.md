## Въпроси към Симо
1. **Клон и push (D-141).** Промптът забранява push; облачната сесия го изисква. Предложение: оставям клона
   `claude/new-session-42gq0n` на GitHub, без PR; кажи, ако искаш да го преименувам на `phase/e0-walking-skeleton`.
2. **D-140 намалява redaction в тесен случай.** Предложение: приеми (тайна след `=` пак се хваща; тест има).
3. **CI `docker-it` е червен до E0.3б**, защото командите още не съществуват. Предложение: остави го (честно червено);
   алтернатива — `if:` по наличие на `docker/sandbox/Dockerfile` до E0.2а.
4. **Къде върви E0.2а.** Тази облачна машина е rootful Docker с cgroup v1, Docker Hub връща 429 за `node:24.22.0-bookworm-slim`
   (pull-ът пада), ghcr blob хостът е блокиран, а S0 иска `proxy start` с твоя ключ в отделен терминал. Предложение: E0.2а
   на твоята машина (rootless, cgroup v2) — или тук, ако разрешиш Docker Hub/ghcr в мрежовата политика на средата; S0 и
   S3 така или иначе трябва да минат на целевата машина.
5. Copyright в NOTICE е „The Mandat authors“ — кажи, ако искаш име.
6. **Push е блокиран (GH013, GitHub push protection).** Комит b94d239 съдържа фалшивите ключове на корпуса като цели
   литерали. Поправката (D-149) е в нов комит, но GitHub сканира всички нови комити. Пренаписването на историята на
   непушнатия клон беше отказано от правата на сесията. Варианти: (а) разреши ми `git filter-branch` върху моите 17
   непушнати комита (само 3 файла се подменят; TDD редът се пази) — препоръчвам; (б) отвори линковете „unblock secret“
   от GitHub (ключовете са фалшиви); (в) аз сквошвам всичко в един комит (губи се червено→зелено следата).
