## Намерено по пътя
- Вратата отказваше scoped npm пакети през prefix маршрут (`%2f`) — тесно изключение само за `/npm/@scope%2fname`.
- Пясъчникът е с `--log-driver none` → статусът на бриджа се чете с `docker exec` (`/status`).
- Целта на MCP маршрута трябва да позволява главни букви (run id е ULID).
- Тестовите файлове на зависимостите (zod) носят примерен JWT → R8 keyscan; махат се при сглобяване на образа.
- Мястото на диска в облака: build cache 22 GB → `docker builder prune` (записано за следващите пускания).
