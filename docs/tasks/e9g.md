# E9ж — професионален десктоп + сайт за изтегляне и документация (v5 т. 5.7; PRD 6.12; план 23.10.2026)

Две неща: (А) **десктоп приложението** — същият дизайн като уеба (същият Next UI, същите токени), с нативен слой,
**локален достъп с разрешения и локални редакции**; (Б) **малък сайт** — изтегляне за macOS, Windows и Linux
и документация с визуализации. Клон: `phase/e9g-desktop-pro`. Нощен workflow: 9 стъпки една след друга (раздел „Нощта“).

Тълкуване на заявката: „ios“ = **macOS** (dmg); за iPhone/Android сайтът насочва към PWA-то, което вече има (D-289).

## Граници (от AGENTS.md, важат цяла нощ)
- Без push, без release, без деплой на сайта, без подписване (правило 3; Q-053/Q-054 по подразбиране). Инсталаторите се строят
  **неподписани локално**; CI файлът строи само artifacts, не публикува.
- Нова зависимост: точна версия, ≥ 3 дни от публикуване (`npm view <pkg> time`), лиценз в license-allowlist.json, ред в
  docs/dependencies.md (правило 8). Всеки факт за Electron/electron-builder: линк + дата в docs/decisions.md, иначе [НП] (правило 9).
- Прозорецът остава заключен (D-303): contextIsolation, sandbox, без nodeIntegration, навигация само към локалния адрес, + CSP.
- Мостът main ↔ уеб е тесен, типизиран и с zod в двата края; схемите са в packages/contract (правило 11).
- Сайтът не праща нищо към нас: без аналитика, без бисквитки, без външни шрифтове (PRD-15).
- Нощта няма кого да пита: при неясно — подразбиране, ред в docs/questions-for-simo.md (Q-0xx с „Избрах по подразбиране“), напред.

### А3. Локален достъп с разрешения и локални редакции (AC-12.6 + „local permissions and edits“)
Модел: приложението **не вижда нищо на диска, докато човекът не даде папка**. Разрешението е за папка и за конкретни права:
| право | какво позволява |
| --- | --- |
| `read` | папката да стане проект (скенерът, огледалото, както днес през CLI) |
| `apply` | „Приложи локално“: `mandat apply --task <id>` (`merge --ff-only`, T3-7; никога reset/checkout -f) в работното копие |
| `open_editor` | „Отвори в редактора“ на файл от diff-а (vscode:// / cursor:// / zed://, избор в Настройки) |
| `terminal` | вграденият терминал върху worktree на хоста (А4), с надпис „не е пясъчник“ |
- [x] `LocalGrant {path, scopes, granted_at}` в contract; записът е само в main процеса (профилната папка), уебът само пита
- [x] Даване: нативен диалог за папка или drag-and-drop/„Отвори с“ → екран „Добави проект“ с предложение (AC-12.6) →
      нативно потвърждение с изброените права (D-373; регистрацията като проект от уеба: Q-061)
- [x] Проверки: realpath (без бягство през symlink), отказ за `/`, домашната папка като цяло и системни папки; пътят от
      задачата трябва да е вътре в дадена папка; всяка употреба → task_activities (не в дневника)
- [x] Настройки → „Локален достъп“: списък, отнемане на право/папка (уеб страница, работи през моста; в браузър е скрита)
- [x] Агентът в пясъчника не получава нищо от това: разрешенията са за човека и харнеса на хоста (тест: env/mount-ове не се менят)
