# Паметта на Мандат в твоите сесии (D-400, D-402)

Паметта живее в базата на `pnpm local` (Postgres на 127.0.0.1:54329). Задачите, които Мандат пуска в пясъчника, я получават
сами (блок в договора). За собствените ти сесии с Claude Code или Codex има MCP сървър `mandat-memory-mcp`.

## Какво получава сесията
- **В началото**: ядрото — „За теб“ (≤ 500 токена) и „За този проект“ (≤ 800 токена) — като инструкции на сървъра.
  Замразено е за цялата сесия (кешът на промпта остава валиден); промените се виждат в следващата сесия.
- **При нужда**: `memory_search` (думи + същности; празно, ако няма нищо общо), `memory_note` (запис), `memory_core`.
- `memory_note` с основание `user_said` (ти го каза) → активно веднага, виждаш го в менюто „Памет“ и можеш да го върнеш.
  С `observed` (агентът го е прочел/видял) → чака твоето одобрение. Правила, права и тайни се отказват.
  Обхват `session` → само за тази сесия, нищо не се записва.

## Свързване с Claude Code
Първо `pnpm build` и `pnpm local` поне веднъж (базата и собственикът трябва да съществуват). После, от папката на проекта:

```bash
claude mcp add --transport stdio mandat-memory -- node /ПЪТ/ДО/AI-Harness-NOIT/packages/memory/dist/main.js --repo mandat-demo/shop
```

`--repo` е името на проекта в Мандат (или id-то му); без него сесията вижда само личната ти памет. За всички проекти
наведнъж: `--scope user` преди името. Друга база: `--env MANDAT_DB_URL=postgresql://…` (между `--env` и името трябва да има
друга опция, напр. `--transport stdio`). Синтаксис: https://code.claude.com/docs/en/mcp (26.10.2026).

Сървърът отказва да тръгне, ако в средата му има ключ на доставчик (ANTHROPIC_API_KEY, OPENAI_API_KEY, SUPABASE_*KEY*),
по същото правило като сървъра `mandat` (S35).
