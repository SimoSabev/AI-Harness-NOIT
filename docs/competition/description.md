# Harnova

Harnova е харнес за AI агенти, които пишат код. Превръща задача в доказано работещ софтуер, без човекът да
преглежда код ред по ред.

Задачата става разговор, одобрена спецификация и скрити приемни тестове, които агентите не виждат. Агентите
(Claude Code, Codex, Gemini, локални модели) работят паралелно в изолирани Docker пясъчници, без истински API ключ и
без мрежа извън контролирана врата. Всеки резултат минава независими проверки D1–D14 в нов пясъчник, записва се във
верижен дневник и се запечатва. Човекът одобрява сливането с втори фактор. Гласовата асистентка Nova говори на
български и управлява екраните.

Приложение за Mac, уеб и телефон. TypeScript, Docker, Postgres, Next.js, Electron.
