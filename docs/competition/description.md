# Harnova

Harnova е система за работа с AI агенти, които пишат код. Целта е резултатът от агентите да се проверява
независимо, преди да влезе в проекта.

Основни функции:
- задачата се уточнява в разговор и става спецификация, която човек одобрява;
- отделен агент пише скрити приемни тестове, които агентите изпълнители не виждат;
- агентите (Claude Code, Codex, Gemini, локални модели) работят в Docker пясъчници без истински API ключ и с мрежа
  само през контролиран шлюз;
- резултатът се проверява в нов пясъчник с проверки D1–D14 и се записва във верижен дневник;
- промяната влиза в проекта само след одобрение от човек;
- гласов агент на български управлява интерфейса.

Технологии: TypeScript, Node.js, Docker, Postgres, Next.js, Electron.
